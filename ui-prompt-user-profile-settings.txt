## III. TRANG 1 — `/user/profile` (Hồ sơ cá nhân)

### Mô tả chức năng
User xem và chỉnh sửa thông tin cá nhân đã đăng ký lúc onboarding. Có thể chỉnh sửa inline với nút Save/Cancel.

### Data fields (từ UpdateUserProfileData):
```ts
fullName: string          // Họ và tên
phoneNumber: string       // Số điện thoại (VN: 0[39]xxxxxxxx)
contactEmail?: string     // Email liên hệ (optional, khác email đăng nhập)
defaultAddress?: {        // Địa chỉ thường dùng (VietMap autocomplete)
  addressText: string
  lat: number
  lng: number
}
vehicleType: 'CAR' | 'MOTORCYCLE'
licensePlate: string      // Biển số xe VN
vehicleColor: string      // Màu xe
```
Read-only (từ AuthContext user):
```ts
email: string             // Email đăng nhập (không đổi được)
role: 'USER'
avatar: string | null     // URL ảnh avatar
```

### Layout nội dung trang (bên trong main scroll area):

**Header Section:**
- Avatar Circle 80px: nếu có user.avatar thì dùng <img>, không thì circle bg C.orange với chữ cái đầu (text-2xl font-bold white)
- Tên hiển thị: font-bold text-xl, color C.navy
- Email subtitle: text-xs, color C.gray
- Badge "Người dùng": bg C.orangeLight, color C.orange, text-xs font-bold rounded-full px-3 py-1
- Nút "Thay đổi ảnh" nhỏ dưới avatar (disabled, tooltip/badge "Sắp ra mắt")

**Card 1 — Thông tin cá nhân** (icon: User, iconBg: C.orangeLight):
- Input: Họ và tên (editable khi isEditing)
- Input: Số điện thoại (editable khi isEditing)
- Input: Email liên hệ (editable khi isEditing, optional)
- Input: Email đăng nhập (luôn disabled, suffix: Lock icon)

**Card 2 — Địa chỉ thường dùng** (icon: MapPin, iconBg: #eff6ff):
- VietMap autocomplete input (clone từ onboarding/user-profile/page.tsx):
  - Debounce 300ms, gọi searchPlaces() từ @/lib/vietmap
  - Dropdown suggestions với icon MapPin + tên địa chỉ
  - Khi chọn: gọi getPlaceDetails(refId) lấy lat/lng chính xác
  - isAddressSelected flag để tránh re-search sau khi chọn
- Nếu đã có địa chỉ: hiển thị pill chip màu C.orangeLight với text địa chỉ + nút X xóa

**Card 3 — Thông tin phương tiện** (icon: Car/Bike, iconBg: #f0fdf4):
- Vehicle Type selector:
  [🚗 Ô tô] [🏍️ Xe máy]
  Hai nút pill; active = bg C.orange + text white; inactive = bg #f1f5f9 + text C.gray
- Input: Biển số xe (auto toUpperCase, validator isValidVietnamPlate từ @/lib/validators)
- Color picker: Grid 5 cột, mỗi ô button 40x40px rounded-xl
  VEHICLE_COLORS = ['Trắng','Đen','Xám','Bạc','Đỏ','Xanh dương','Xanh lá','Vàng','Cam','Nâu']
  COLOR_HEX map tương ứng
  Selected: ring-2 ring-offset-1 ring-[C.orange] + checkmark icon trắng
  Ô cuối "Màu khác": gradient + khi click → show text input bên dưới

**Edit Flow:**
- Mặc định: tất cả input disabled (read-only view)
- Nút "Chỉnh sửa" (Pencil icon + text) ở top-right của trang → setIsEditing(true)
- Khi isEditing=true: hiện sticky bar ở bottom (mobile) / inline row (desktop):
  [Hủy — secondary] [Lưu thay đổi — primary gradient]
- isDirty = JSON.stringify(form) !== JSON.stringify(original)
- Cancel: reset form về original, setIsEditing(false)
- Save: validate → API PUT /me/profile → toast.success → update original → setIsEditing(false)

### API Calls:
```ts
GET  /me/profile    → load data vào form & original state
PUT  /me/profile    → body: UpdateUserProfileData
```

### API endpoints:
```ts

POST /me/change-password  → body: { currentPassword: string, newPassword: string }
```

### UpdateUserProfileData (từ @/lib/auth.ts):
```ts
export interface UpdateUserProfileData {
    fullName: string;
    phoneNumber: string;
    contactEmail?: string;
    defaultAddress?: { addressText: string; lat: number; lng: number; };
    vehicleType: 'CAR' | 'MOTORCYCLE';
    licensePlate: string;
    vehicleColor: string;
}
```

### Validation rules:
- fullName: required, trim
- phoneNumber: /^0[39][0-9]{8}$/ (số VN)
- contactEmail: optional, nếu có thì /^[^\s@]+@[^\s@]+\.[^\s@]+$/
- licensePlate: isValidVietnamPlate() từ validators.ts; normalize với normalizeVietnamPlate() trước khi gửi API
- Password: currentPassword required, newPassword min 6, confirmPassword === newPassword

## VIII. UX DETAILS

1. **Loading skeleton:** Khi fetch data ban đầu, hiển thị pulse skeleton thay vì spinner:
   - Mỗi input field: `<div className="w-full h-11 rounded-xl bg-gray-200 animate-pulse" />`
   - Avatar: `<div className="w-20 h-20 rounded-full bg-gray-200 animate-pulse" />`

2. **isDirty detection:**
   ```ts
   const [original, setOriginal] = useState<ProfileData | null>(null);
   const [form, setForm] = useState<ProfileData>({...});
   const isDirty = JSON.stringify(form) !== JSON.stringify(original);
   ```

3. **Vehicle color — COLOR_HEX mapping:**
   ```ts
   const COLOR_HEX: Record<string, string> = {
       'Trắng': '#ffffff', 'Đen': '#1a1a1a', 'Xám': '#6b7280',
       'Bạc': '#c0c0c0', 'Đỏ': '#ef4444', 'Xanh dương': '#3b82f6',
       'Xanh lá': '#22c55e', 'Vàng': '#eab308', 'Cam': '#f97316', 'Nâu': '#92400e',
   };
   ```

4. **Logout confirm (không dùng window.confirm()):**
   ```tsx
   {!isConfirmLogout ? (
     <button onClick={() => setIsConfirmLogout(true)} ...>
       <LogOut /> Đăng xuất
     </button>
   ) : (
     <div>
       <p>Bạn có chắc chắn muốn đăng xuất không?</p>
       <div className="flex gap-3">
         <button onClick={handleLogout} ...>Xác nhận đăng xuất</button>
         <button onClick={() => setIsConfirmLogout(false)} ...>Hủy</button>
       </div>
     </div>
   )}
   ```

5. **Responsive grid:**
   - Mobile (<md): single column
   - Desktop (md+): `grid grid-cols-1 md:grid-cols-2 gap-4` cho Cards (profile/settings)
