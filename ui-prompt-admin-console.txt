Bạn là một senior product designer kiêm senior frontend engineer. Nhiệm vụ của bạn là thiết kế bộ giao diện Admin hoàn chỉnh cho RescueMe, một nền tảng cứu hộ xe khẩn cấp. Mục tiêu là tạo ra một admin console production-ready, bám rất sát design language đang có ở frontend hiện tại, không làm app trông như một hệ thống khác.

Yêu cầu quan trọng nhất: giao diện Admin phải đồng bộ với các UI hiện có của RescueMe, đặc biệt là các màn auth, user, provider, wallet, request flow. Không dùng phong cách dashboard SaaS generic màu tím, không dark mode mặc định, không typography xa lạ, không tông enterprise lạnh tách biệt khỏi sản phẩm hiện tại.

==================================================
I. DESIGN LANGUAGE BAT BUOC
==================================================

1. Typography
- Font family chính: Poppins, sans-serif
- Font phụ: Roboto cho text hỗ trợ hoặc dữ liệu phụ nếu cần
- Tổng thể ưu tiên cảm giác hiện đại, rõ ràng, ấm, tin cậy, không quá corporate khô cứng

2. Color palette phải bám hệ hiện tại

const C = {
  orange: '#f97316',
  orangeDark: '#ea6c0a',
  orangeLight: '#fff7ed',
  navy: '#1a1a2e',
  gray: '#6b7280',
  border: '#e2e8f0',
  bg: '#f4f6f9',
  bgSoft: '#f8fafc',
  green: '#16a34a',
  greenLight: '#f0fdf4',
  red: '#ef4444',
  redLight: '#fef2f2',
  yellow: '#ca8a04',
  yellowLight: '#fefce8',
  blue: '#2563eb',
  blueLight: '#eff6ff',
};

3. Visual character
- Nền chính sáng, dùng bg xám rất nhạt giống user/provider screens
- Card trắng, bo góc 16px-24px, shadow nhẹ
- Accent cam là brand color chính cho active state, CTA chính, highlight trạng thái đang xử lý
- Icon dùng Lucide hoặc line icon đơn giản, stroke gọn, không dùng icon 3D
- Border mảnh, sạch, thiên về slate thay vì đen
- Không lạm dụng gradient, chỉ dùng cho primary CTA, hero card, KPI highlight quan trọng

4. Layout principle
- Desktop-first cho admin vì nghiệp vụ nhiều bảng, bộ lọc, thao tác hàng loạt
- Mobile vẫn phải usable: table chuyển thành stacked cards, filter chuyển thành drawer/bottom sheet
- Spacing rộng, không dồn đặc. Ưu tiên cảm giác vận hành có kiểm soát, không rối mắt

5. Component pattern cần tái sử dụng
- Page shell: sidebar trái + topbar + vùng content scroll riêng
- Sidebar: nền trắng, border phải mảnh, active item dùng C.orangeLight + text C.orange
- Topbar: sticky nhẹ, chứa title, search, filter nhanh, trạng thái hệ thống, avatar admin
- Card: rounded-2xl bg-white border nhẹ shadow-sm
- Table: header nền rất nhạt, row hover subtle, action column rõ ràng, sticky toolbar khi bulk select
- Filter chips: rounded-full, active màu cam nhạt/cam đậm, inactive màu xám nhạt
- Primary button: gradient cam từ C.orange sang C.orangeDark, text trắng, rounded-xl
- Secondary button: nền trắng hoặc bgSoft, border C.border, text C.navy/C.gray
- Danger button: nền red hoặc redLight tùy mức độ
- Status badge: pill nhỏ, icon + label, màu theo trạng thái
- Drawer/modal: bo góc lớn, header rõ, footer sticky với CTA
